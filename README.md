# Fluencis

A web application designed to help students practice spoken communication and build speaking fluency.

## Live Application
- **Live URL:** [Fluencis](https://speakmate-student-communication-practice-289161226215.asia-southeast1.run.app/#Fluencis)

## Overview & Key Features
- Interactive speaking practice prompts tailored for students
- Browser-based interface deployed on Google Cloud Run (`asia-southeast1`)
- Tested across core user flows, input validation, and browser responsiveness

## Development & QA Notes
- Prototyped using Google AI Studio and deployed to Google Cloud Run
- Manually verified UI layout, prompt transitions, and hash-route navigation
